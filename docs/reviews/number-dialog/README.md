# Produktbilder: tallendringsdialog #25

Faktiske Chromium-bilder fra `tests/e2e/number-dialog.spec.ts` mot produksjonsbygget. De viser GP-dialogen på 390 × 568 px og 320 × 568 px med 200 % tekst. Markert 0, Før/Etter og de parallelle hjulene er kontrollert visuelt. Kort skjerm har redusert illustrasjon for å bevare tall og handlinger.

![GP-dialog, 390 px](money-390.png)

![GP-dialog, 320 px og stor tekst](money-320-large-text.png)

Bildene dokumenterer layout, ikke fysisk iPhone, tastatur eller inerti. Se [kravmatrisen](../../CHARACTER_WORKSPACE.md#kontrollresultat-og-dekning-for-25) og [telefonprøvene](../../TESTING.md#test-av-tallendringsdialogen-25).
