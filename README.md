# D&D Character Companion

Et mobilførst, lokalt lagret D&D 5e (2014) karakterark. Målet er å erstatte papirarket, ikke bygge en kampmotor eller fullautomatisk karakterbygger.

## Prosjektets arbeidsdokumenter

1. [Kravspesifikasjon](docs/REQUIREMENTS.md) – gjeldende funksjonelle krav og akseptansekriterier.
2. [Datamodell](docs/DATA_MODEL.md) – domenekontrakt og invariants.
3. [Designbrief](docs/DESIGN.md) – visuell retning, låste UX-mønstre og forslag om designalternativer.
4. [Overlevering til Codex](docs/CODEX_HANDOFF.md) – implementasjonsplan, testansvar og kjente regresjoner.
5. [Beslutningslogg](docs/DECISIONS.md) – bakgrunn, beslutninger og forkastede retninger.

**Kildeprioritet:** Gjeldende krav/beslutninger > godkjente prototypemønstre > visuell form. Prototypen v0.11 har kjente feil og skal ikke implementeres ordrett.

Prosjektet er i overgang fra utforskende prototyper til en modulær, testet applikasjon. Eksisterende GitHub Pages-implementasjon er ikke fasit for framtidig produkt.
